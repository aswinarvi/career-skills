# Writing rules: bullets, honesty, and avoiding the AI fingerprint

## Bullet formula

Every experience/project bullet is one achievement, past tense, **strong verb first**, quantified where a
real number exists. Two interchangeable frames:

- **XYZ** — "Accomplished **X**, measured by **Y**, by doing **Z**."
  → *"Cut app cold-start time 38% by lazy-loading feature modules and deferring analytics init."*
- **STAR (compressed)** — Situation/Task implied, **Action** + **Result** stated.
  → *"Migrated 140-screen app from Provider to Riverpod, eliminating a class of rebuild bugs that drove ~20% of crash reports."*

Guidelines:

- Lead with impact when you can (result-first reads stronger than task-first).
- One idea per bullet. If it has an "and also", split it.
- 3–5 bullets for the most recent/relevant role; taper to 1–2 for older ones.
- Prefer concrete nouns and systems over vague scope words ("various", "multiple", "several stakeholders").

## Strong verbs (start bullets with these, not "Responsible for")

- **Built / shipped:** built, shipped, launched, developed, implemented, engineered, automated, integrated.
- **Improved:** cut, reduced, accelerated, optimized, streamlined, hardened, refactored, stabilized.
- **Led:** led, drove, owned, coordinated, mentored, spearheaded* (see banned list — use sparingly).
- **Analyzed:** diagnosed, root-caused, profiled, instrumented, measured, benchmarked.

Vary the openers — five bullets that all start with "Led" read as filler.

## Anti-fabrication (non-negotiable)

The resume may only contain things the user actually did. Never invent or inflate:

- **No invented facts** — employers, titles, dates, degrees, certifications, tools, or team sizes that the
  user didn't state.
- **No fabricated metrics.** A number must come from the user. If a bullet is begging for a figure the user
  didn't give, do one of: (a) ask for it, or (b) write the bullet without the number. Never guess "40%".
- **Verb discipline — don't overclaim ownership.** Match the verb to the real level of involvement:

  | User said | OK | Not OK |
  |---|---|---|
  | "helped with the migration" | "Contributed to", "Supported" | "Led", "Owned", "Architected" |
  | "was on the team that built X" | "Built X as part of a 5-person team" | "Single-handedly built X" |
  | "fixed some bugs" | "Resolved crash bugs in the checkout flow" | "Overhauled the checkout system" |

- **Reframing is allowed; lying is not.** Repositioning real experience toward a target role (emphasis,
  ordering, terminology the field uses) is the whole point. Inventing experience to fit the target is not.
- When tailoring to a JD, surface **honest gaps** to the user ("the JD wants Kubernetes; nothing in your
  history mentions it") rather than papering over them.

## Avoid the AI fingerprint

Recruiters increasingly recognize LLM-generated prose. After drafting, scan and fix:

**Banned / overused words** (replace with plain equivalents): spearheaded (unless truly apt), leveraged (→
"used"), utilized (→ "used"), delve, showcase, robust, seamless, seamlessly, cutting-edge, best-in-class,
synergy, holistic, tapestry, myriad, plethora, "passionate about", "results-driven", "detail-oriented",
"proven track record", "team player", "go-getter", "wear many hats".

**Structural tics to remove:**

- The "not only X, but also Y" construction.
- Tricolons everywhere ("designed, developed, and deployed") — fine once, grating every line.
- Em-dashes in every sentence — vary punctuation.
- Every bullet the same length and rhythm — vary them.
- Empty intensifiers: "significantly", "successfully", "effectively", "various", "numerous".

**Post-generation scan (do this before presenting):** re-read every bullet and the summary; if a phrase
could appear verbatim on a thousand other AI-written resumes, rewrite it in the user's plainer, more specific
terms. Specificity (real systems, real numbers, real constraints) is what makes it read human.

## Tone

Plain, confident, concrete. No adjectives doing the work that a metric should do. If you cut every word that
adds no information, what remains is usually the good resume.
